# 批注: Enter stacks, Ctrl+Enter sends to the 主会话

A 批注 is not a Side Chat turn. Enter adds it to the composer as a stackable attachment (Codex's "N annotations" chip). Ctrl+Enter sends immediately to the 主会话. Clicking send after stacking does the same. If the 主会话 is busy, the send queues exactly like an ordinary user message.

Sending 批注 into Side Chat, or auto-firing every mark, was rejected: 批注 is an instruction to the 主会话 that is doing the work.
