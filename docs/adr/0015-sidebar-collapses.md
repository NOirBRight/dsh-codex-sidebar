# The 侧栏 collapses; a 侧栏开关 pulls it back

Closing the last Tab hides the 侧栏 instead of leaving an empty Palette Tab. A Codex-style toggle at the top shows or hides it. The Tab strip stays with the 主会话, so showing the 侧栏 again restores the tabs.

Clicking a file/URL in the 主会话, a shortcut that opens a 工具, or picking from the Palette, expands the 侧栏 and opens or reuses the Tab. The toggle remains the human's manual hide/show.

Keeping a permanent empty Tab was rejected. Requiring the toggle before preview was rejected: click-to-preview would die while the 侧栏 is hidden.
