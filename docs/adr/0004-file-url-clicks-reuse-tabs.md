# File and URL clicks reuse a Tab by target

Clicking `src/Login.tsx` opens or focuses a Files Tab for that path. Clicking a page URL opens or focuses a Browser Tab for that URL. Same target reuses; a different target may open another Tab of the same 工具.

批注 still stack on the 主会话 composer (Enter) or send to the 主会话 (Ctrl+Enter), never into Side Chat, regardless of which Tab is focused.
