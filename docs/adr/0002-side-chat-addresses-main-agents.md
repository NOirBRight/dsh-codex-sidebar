# Side Chat is a Fork; it may message other 主会话s

Side Chat is not a second 主会话. It is a Fork of the left-hand 主会话 (主Agent / 舵主 are the same object). It answers in its own Tab. It cannot spawn. It may send messages to other 主会话s — other DSH conversations — not to subagents.

Attachment (whose 侧栏 this is) and addressing (who a send goes to) are different knobs. The Fork always comes from the 主会话 the 侧栏 is attached to.
